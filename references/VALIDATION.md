# 验证范围

2026-10-07 的原始开发环境为 Windows，官方 Codex 测试包包括 26.930.7945.0。验证未把个人截图或运行日志放入此包。

- 真实桌面快捷方式连续启动四次：同一应用、浏览器、壁纸 helper 和媒体；一个入口、一个媒体节点；采样期间无超过 50ms 的长任务，壁纸恢复没有报错。
- PowerShell 隔离场景：冷启分支、端口冲突、慢就绪、缺失 helper/陈旧状态、健康重复点击、普通官方启动、损坏状态。
- CDP 协议模拟：主窗口晚到、上下文瞬时错误、只接入主窗口、同 URL 刷新、官方浏览器更换后 helper 退出。
- 原始素材读取：当前四个可用场景与已验证原 PNG/JPEG 字节逐一相同；复杂多层场景隐藏。发布包不携带这些素材或项目 ID。
- 原始 PNG 数据保持、包路径越界、歧义场景隐藏、缓存读写，以及完整 payload 语法、媒体路径包含关系和去重都有隔离测试。
- 设置性能先前实测开关约 69–126ms，改用顶层 popover 后约 16–53ms；这不是所有电脑的性能保证。

打包后另检查逐文件 SHA-256、默认素材来源、无个人资料、完整展开后的离线测试及安装条件检查。安装器在隔离目录实际完成首次安装、再次安装、旧引擎备份与设置保留；快捷方式目标和七尺寸图标独立核对。实际跨电脑执行与真实冷启动需要在目标机器完成；本地测试不会为此关闭正在使用的 Codex。

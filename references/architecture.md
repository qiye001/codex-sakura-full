# 实现与会话成果汇总

## 最终方案

Windows 使用 ritual-ink-codex-theme-launcher 的落樱启动流程；开场移植 panding999/codex-startup-animation 的 HTML/CSS/Canvas 前端。不是独立壁纸软件的悬浮窗口，也没有修改官方 app.asar。官方界面由原来的应用渲染，本机 CDP 连接只负责外观接入、已允许的壁纸文件读取与恢复。

桌面入口通过隐藏运行器调用 PowerShell，保留 Store 包的正式应用身份；开启仅回环地址的调试连接，Node 辅助进程挂载样式、设置按钮和动画。启动检测使用浏览器 ID 与真实进程端口，避免把“浏览器已启动、页面还未就绪”误认为需要重启。

## 已整合的界面与体验

- 壁纸入口嵌入左侧原生图标栏，只显示图片图标；提示仅“壁纸”，使用原生色值、hover wash、圆角与 tooltip 变量。
- 左侧图标栏和对话栏透明，清除各自的磨砂和深色块；外层仅保留原动画项目的 `rgb(20 18 24 / .18)` 轻暗层。选中对话是 9% 白色高亮，无紫色内描边。
- 背景覆盖整个内容区，包含侧栏和输入框两侧；移除聊天外圈、底板与路由过渡渐变造成的黑边，保留输入框本身的表面与圆角。
- 同一张已解码壁纸在聊天切换和新图加载期间保持，避免主动清除后闪黑。所有新媒体先验证，再交换 DOM 和释放旧 URL。
- 一个统一“外观设置”窗口容纳壁纸与动画两页；固定标题、关闭按钮和滚动区。切页保留动画草稿和滚动位置。
- 深色应用内下拉菜单替代白底系统菜单，长文件名换行；菜单支持键盘，窗口支持 Esc 和焦点循环。
- 设置窗口使用手动顶层 popover 配合独立遮罩，避免 native showModal 对大量聊天 DOM 计算 inert 引发延迟。
- 图库按 ID/指纹复用，列表 GIF 冻结为静态缩略图；原视频不因此改变。
- 原版约 12 秒动画保留，支持跳过、重播、头像/背景/文字编辑与五种 Windows 字体样本。
- 桌面图标使用七尺寸官方应用标识；每台机器安装时重新生成快捷方式，包内不放旧机器的绝对路径快捷方式。

## 原图与缓存

原上传图片/视频保存于当前应用源 IndexedDB；Workshop 只记录项目 ID、参数及媒体缓存，Steam 路径在目标机器重新发现。每张原始素材绑定源包大小与修改时间，更新后不复用旧底图。主画面不使用 256px 预览放大冒充高清。

`workshop-originals.mjs` 读取 PKG 索引与被引用的 JSON/TEX 数据，不执行场景脚本，不将包内容解压写到任意路径。只接受明确的原始 PNG/JPEG 和可辨识单底图；歧义多层项目隐藏。缓存存在目标机器 `%LOCALAPPDATA%\SakuraUser\workshop-originals`。

新机器使用的默认 `theme.json` 不含原电脑的 highResWorkshop 注册表。本包不包含 Workshop 图片、个人上传图片或 IndexedDB 导出。

## 启动修复

启动锁阻止多次双击并行；复用健康辅助进程，记录状态后再等待壁纸就绪；验证慢时继续恢复，不删除状态和终止应用。只对经过路径/命令行身份确认的本扩展辅助进程进行替换，避免陈旧 PID 误杀。图标同步不再决定壁纸启动成功与否。

默认壁纸与用户本地设置先恢复，Steam 检测异步进行；场景解析在打开设置后按需运行。自动动画等主界面、壁纸和窗口可见后播放；附加到已有会话不重播。排除宠物、网页和分离窗口；页面执行上下文重建、临时错误和同地址刷新可恢复。浏览器关闭/更换后旧辅助进程退出。

完整 payload 按源文件/图片指纹缓存；清除 CDP 响应超时计时器。DOM 观察器消费自己同步写入的记录，避免样式维护自触发循环。

## 原版动画的可编辑性

日常图片、三处文字、字幕字体无需修改代码。源码可编辑时间轴、粒子、碎片、轮廓、转场与 CSS；更改后从 Windows 引擎目录执行 `bin/node/node.exe scripts/build-startup.mjs`。构建器读取旁边的原项目，合并统一设置和字体样本，重建 injector 内的动画 bundle。默认图片替换要同步重建轮廓，避免线稿与彩色图错位。

调试仅替换辅助进程或样式，保留当前 Codex 会话。发布/重新打包前重新生成清单与 ZIP；不要把调试证据、运行状态或本机素材加入发布包。

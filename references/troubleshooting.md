# 安装与启动排查

| 表现 | 检查与处理 |
| --- | --- |
| 点击图标无壁纸 | 先看 launch.log、injector-status.json、injector-error.log；不要先重装官方 Codex。 |
| 已从官方普通入口打开 | 调试连接无法在该会话事后开启；正常退出一次，再使用新桌面 Codex 入口。启动器不会自动关闭它。 |
| 多次点击后迟迟未就绪 | 看状态是否 starting/restoring，核对 helper PID、浏览器 ID、端口与心跳；不以页面未出现为由杀主进程。 |
| helper 退出 | 核对 Node 可读性、模块缺失、包校验和 stderr；下次桌面点击会重建本扩展 helper。 |
| 提示找不到脚本 | 重新执行安装器，重建指向当前用户目录的快捷方式；不复制旧电脑的 .lnk。 |
| 设置按钮缺失或错位 | 可能是官方 DOM 更新，检查主窗口 target 与实际导航栏选择器；不要注入宠物/网页/分离窗口。 |
| 新 Workshop 项目未出现 | 打开/重开设置，等待后台解析；检查 Steam 库及项目的原始媒体。歧义场景和无原始文件的项目隐藏。 |
| 图片模糊 | 核对实际媒体分辨率与来源；不放大预览替代原图，也不声称放大能补回细节。 |
| 图片有留白 | 区分背景容器不透明与 contain 原图比例留白；默认 cover 全应用背景，保留输入框表面。 |
| 需要重新登录 | 不清理资料、不添加新的 user-data-dir、不复制旧机器 cookies；先确认正式 Store 包身份、官方更新和账号状态。此前根因尚未证实，不能把外观接入成功等同于登录永不失效。 |
| EFS 文件读取失败 | 安装器只对已验证的自身安装路径解密；不递归处理整个用户目录。 |

包内有独立便携 Node，不要求配置全局 PATH。正式启动只使用已注册的 `OpenAI.Codex` Store 包。恢复与卸载脚本保留用户资料；要结束回环调试连接，需要用户正常退出该次 Codex，再从官方入口打开。

官方更新后先检查界面和连接，再调整外部引擎；不要修补官方包。没有实机证据时，区分“脚本/协议测试通过”“当前会话恢复通过”和“真实冷启动/另一台机器验证”。

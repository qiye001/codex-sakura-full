# 完整使用手册

## 1. 安装前

适用于 Windows 10/11 x64。先安装 Microsoft Store 官方 Codex，并确认官方入口能正常打开、已完成首次登录。此包不安装官方应用，也不替代官方账号服务。

普通用户下载 GitHub Release 的 Windows ZIP；它包含便携 Node。GitHub 的 Source code ZIP、仓库 clone 不包含 node.exe，开发者需安装 Node 22 或更新版本。

把完整 ZIP 解压到普通本地文件夹。解压目录、用户名可以含中文和空格；不要在压缩包内直接双击脚本。保留原包有助于以后诊断、还原和重新安装。

## 2. 首次安装与启动

1. 双击包根目录的 **Install.cmd**。
2. 安装器校验文件、验证官方 Store 包和 Node、暂存并验证引擎、保留旧设置、备份旧引擎。
3. 完成后会生成桌面 **Codex** 图标、开始菜单 **Codex Sakura → Codex** 入口，以及当前用户的 `codex-sakura-full` 技能。
4. 若正在普通模式使用 Codex，请保存未发送输入，再从应用菜单退出整个应用。只关闭窗口不一定结束后台进程。
5. 双击桌面 **Codex** 图标。若当前会话已启用外观连接，则直接恢复；不会为了开启外观强制结束主应用。

安装器需要对当前用户目录的写权限，不要求修改官方安装目录。已有同名且不属于本包的桌面快捷方式会在旁边留下备份。默认初次壁纸为落樱示例，动画使用上游默认素材与文字。重复安装保留已有选择。

只需检查条件时，运行 `Install.ps1 -CheckOnly`。需要安装但不立即启动时，运行 `Install.ps1`。`Install.cmd` 默认安装并请求启动。

## 3. 日常操作

- 日常启动只使用桌面 **Codex** 图标，不需重复安装。
- 第一次冷启动播放约 12 秒开场；点击“跳过”或按 Esc 可以跳过。
- 应用已运行时再次点击图标会复用健康辅助进程，不重播开场。
- 左侧图片图标的悬浮提示是“壁纸”，它打开统一的外观设置。
- “壁纸”和“启动动画”是独立页签，拥有独立媒体选择。
- Ctrl + Alt + B 可打开启动动画设置。设置中按 Esc 关闭菜单或当前设置层。

技能安装后，在新的一轮或新会话中可使用 `$codex-sakura-full`；若列表未刷新，可直接指定解压包内 `SKILL.md`。技能帮助安装和维护，实际外观由运行引擎实现。

## 4. 壁纸图片与视频

在“壁纸”页签上传本地媒体。支持 PNG、JPEG、WebP、GIF、BMP、AVIF、MP4、WebM，单文件上限 128 MB。扩展名支持不等于所有编码都支持；Chromium 必须成功解码。优先采用常见 H.264 MP4 或 WebM。

新媒体在成功解码后才替换旧背景，失败时保留当前媒体。默认按比例铺满应用与侧栏：宽高比不同会裁剪边缘。需要全图时选择“完整显示”，可能出现空余区域；原始尺寸、拉伸和对齐选项具有各自的显示结果。降低遮罩可使壁纸更清楚，过低可能影响文字可读性。

视频可以暂停。列表中的缩略图仅用于选取，主背景使用实际媒体；GIF 列表预览可能冻结为静态图。

恢复初始壁纸：在壁纸页签选择恢复落樱默认，不会覆盖动画图片与文字。

## 5. Wallpaper Engine 本地项目

外观设置从**本机** Steam 注册信息及库目录发现 Workshop 项目，无需复制其他电脑的缓存。无需为 Codex 另外启动 Wallpaper Engine，但对应素材必须已经存在本机。

- 视频项目：读取原视频，仍需 Chromium 支持其编码。
- 明确的单底图场景：按需读取可可靠识别的原始 PNG/JPEG，作为高清静态壁纸。
- 复杂多层、Spine、网页或无法确认完整底图的项目：隐藏或不作为可应用项显示。

不会把预览图放大冒充原图，也不会复现 Wallpaper Engine 全部动画、时钟、音频响应和合成效果。首次打开设置可能需要后台解析；新下载项目约每 15 秒检查一次，也可重新打开设置。源包大小和修改时间用于识别缓存是否失效。

## 6. 启动动画与文字

在“启动动画”页签分别更换前段头像、后段背景、标题、小字、字幕及字体样式，保存并预览。空文字可以隐藏对应内容。主壁纸不会因此更换。

恢复原始图片与文字时，点击动画恢复默认并保存；字体另选“原版样式”。Windows 字体样本用于比较实际显示结果。若某字体未安装，系统可能使用后备字体。

日常修改图片与文字无需编辑代码。修改节奏、碎片、线稿、转场或时间轴需编辑动画源码并重新构建，见 [开发说明](DEVELOPMENT.md)。

## 7. 数据位置与备份

| 内容 | 位置 |
|---|---|
| 已安装引擎 | `%LOCALAPPDATA%\SakuraUser\engine` |
| 当前主题资源 | `%LOCALAPPDATA%\SakuraUser\active-theme` |
| 启动日志 | `%LOCALAPPDATA%\SakuraUser\launch.log` |
| 辅助进程日志 | 同目录 `injector.log`、`injector-error.log` |
| 当前状态 | 同目录 `state.json`、`injector-status.json` |
| 原图解析缓存 | 同目录 `workshop-originals` |
| 旧引擎备份 | 同目录 `engine-backup-*` |
| 当前用户技能 | `$CODEX_HOME/skills/codex-sakura-full`，默认 `~/.codex/skills/codex-sakura-full` |
| 上传媒体与应用内选项 | 当前官方应用源的本机 IndexedDB |

账号、聊天和官方应用资料由官方应用管理；本包不会打包、迁移或清理它们。不要把整份用户资料、IndexedDB、Cookie、上传媒体或 Workshop 缓存放入公开 Issue 或仓库。

卸载后重装保留的选择与跨电脑迁移是不同操作。本包没有提供账号或个人图片的跨电脑自动同步功能。

## 8. 更新

保存工作，下载新 Release 完整解压，再运行新包的 Install.cmd。已有主题与文字选择应保留，旧引擎会备份。不要用单个新文件覆盖旧引擎。

官方 Codex 更新可能改变 DOM、窗口或 CDP，出现故障时先诊断，不保证任意未来版本自动兼容。重新登录可能由官方账号服务或运行环境变化引起；本包不能承诺永不要求重新登录。

## 9. 验证是否真正启动成功

运行 `scripts/diagnose.ps1`，确认：官方主进程携带本机调试端口；`WallpaperStatus.phase` 是 `ready`；`readyTargets` 至少为 1；脚本确认外观注入标记存在。

视觉上还应核对主窗口中仅有一个壁纸入口、实际媒体已显示、设置可以打开。编译或文件校验通过不等于实际界面验收通过。

## 10. 恢复与卸载

`Uninstall.ps1 -RestoreOnly` 只恢复官方外观并停止本扩展的已验证辅助进程，保持当前应用与个人选择。

`Uninstall.ps1` 移除运行引擎及属于本包的桌面、开始菜单入口；保留账户、聊天、保存选择、上传媒体和技能文档。技能需要移除时，可在 Codex 技能管理界面单独移除。

恢复样式不会关闭已经开启的调试连接。要结束该连接，正常退出整个 Codex，再从官方开始菜单入口打开。不要通过删除官方资料目录来恢复外观。

## 11. 支持与反馈

查看 [故障排查](TROUBLESHOOTING.md)，仍失败时在 GitHub Issue 提供：Windows 版本、官方 Codex 包版本、本项目版本、启动入口、具体报错和已脱敏日志。不要提供登录凭据、客户资料或聊天截图。
